Portfolio personnel

Site vitrine en HTML/CSS présentant mes compétences et projets.

À propos du projet

Ce portfolio personnel a été conçu pour présenter mes compétences en développement web et mon parcours professionnel. L'objectif était de créer un site vitrine moderne, responsive et accessible.

Le design met en avant une interface épurée avec une navigation intuitive. La page d'accueil présente mon profil, tandis que les sections compétences, projets et contact permettent aux visiteurs de découvrir mon travail.

Fonctionnalités

  • Design responsive (mobile, tablette, desktop)
  • Navigation fluide entre les sections
  • Formulaire de contact fonctionnel
  • Animations CSS au survol
  • Structure sémantique HTML5

Technologies utilisées

HTML5 CSS3 Flexbox Grid Responsive Design

Application météo

Interface utilisateur pour une app météo (HTML/CSS/JS).

À propos du projet

Cette application météo affiche les prévisions pour différentes villes. L'interface utilisateur est moderne et intuitive, avec des icônes météo dynamiques et des animations.

L'application utilise l'API OpenWeatherMap pour récupérer les données météo en temps réel et les afficher de manière claire et attrayante.

Fonctionnalités

  • Recherche de villes
  • Affichage température, humidité, vent
  • Icônes météo dynamiques
  • Prévisions sur 5 jours
  • Géolocalisation automatique

Technologies utilisées

HTML5 CSS3 JavaScript API REST Fetch API LocalStorage
